# Sumi for macOS

[**Sumi 0.1.4をダウンロード**](https://raw.githubusercontent.com/arimoteeee-blip/SumiUpdates/main/releases/v0.1.4/Sumi-0.1.4.zip)

macOS 14以降。Apple Silicon・Intel両対応。PDFの閲覧・ハイライト・見開き・分割表示に対応した開発版です。

## 初回の入れ替え

1. 起動中のSumiを⌘Qで終了します。
2. ダウンロードしたZIPを開き、中のSumi.appを、現在Sumiを置いているアプリケーションフォルダへコピーして置き換えます。初期インストーラを使った場合は、Finderの「移動」→「フォルダへ移動」で `~/Applications` を開きます。
3. Sumiを開き、メニュー「Sumi」→「Sumiについて」で0.1.4を確認します。

この一度の入れ替えで更新先と検証用公開鍵が設定されます。以後は「Sumi」→「アップデートを確認…」から確認できます。自動確認・ダウンロードは「設定」→「アップデート」で変更できます。アプリ起動中の確認間隔は約24時間です。新しい版の適用には終了または再起動が必要です。

PDF・注釈はアプリ本体の外に保存されます。アプリを更新するときに、保存データのフォルダを削除する必要はありません。

## 今回の改善

- 文字選択ハイライトと、スキャンPDFへドラッグして引く蛍光ペン。
- 見開き・表紙の単独表示・右開き・見開き単位のページ送り。
- 文書ごとの表示設定の保存。
- 本棚・フォルダ・タブと閲覧ツールの操作領域。
- 署名付き更新情報とアプリ内の更新確認。

## 署名と検証範囲

更新アーカイブとフィードにはEd25519署名を付けています。アプリ自体はアドホック署名で、AppleのDeveloper ID署名・公証は未実施です。そのため、ダウンロード後の初回起動をmacOSが制限する場合があります。利用者のMacでの初回導入は未検証です。

ビルド、注釈の保存・Undo/Redo、本棚・フォルダ・タブのUI試験はGitHubのmacOS環境で実行しています。公開先から更新を検出し、テスト用アプリをbuild 5から6へ入れ替え、更新後に最新版と判定される試験も成功しました。実際の旧版からのデータ移行や、利用者のMacでの再起動を確認した試験ではありません。Intelでの起動、macOS 14での動作、実機での長時間スクロールやバッテリー消費は未検証です。

このリポジトリにはアプリと更新情報だけを置きます。ソースコード、秘密鍵、利用者のPDF・注釈は公開しません。
