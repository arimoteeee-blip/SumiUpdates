# Sumi for macOS

[**Sumi 0.1.5をダウンロード**](https://raw.githubusercontent.com/arimoteeee-blip/SumiUpdates/main/releases/v0.1.5/Sumi-0.1.5.zip)

macOS 14以降。Apple Silicon・Intel両対応の開発版です。

## 更新する

0.1.4（build 6）を利用中の場合は、Sumiメニューの「アップデートを確認…」から更新できます。自動確認・ダウンロードは「設定 → アップデート」で変更できます。アプリ本体の更新適用には終了または再起動が必要です。

それ以前の版や初回導入では、ZIPを開き、Sumiを⌘Qで終了してから、Sumi.appを現在のアプリケーションフォルダへコピーしてください。初期インストーラを使った場合の保存先は `~/Applications` です。Finderの「移動 → フォルダへ移動」で開けます。起動後は「Sumiについて」で0.1.5を確認してください。

PDF・注釈はアプリの外に保存されます。保存データのフォルダを削除する必要はありません。旧版データの初回書き込み前には復旧用スナップショットを保存します。0.1.5で使ったライブラリを旧版のアプリで編集しないでください。

## 0.1.5の主な変更

- 本棚・フォルダ・タブのクリック、フォルダへのドラッグ移動、複数選択、表紙表示を改善。
- 単ページ・見開き・表紙単独・右開き、縦横の分割、目次、ページ一覧に対応。
- ハイライト・下線・取り消し線、手書き・消しゴム、文字・写真・四角、左右の手書きコメント、注釈の移動・変形・複製・Undoを整備。
- 白紙・罫線・方眼のノート、拡張キャンバス、まとめノート、教材間の参照、復習印、ページ編集・以前の版への復元を追加。
- 旧.sumiのページ構成、独立OCR文字、写真、手書きコメント、筆圧情報等の取り込みを拡張。
- PDFの文字から目次候補を作り、見出しと階層を確認して追加。

## TomeでOCRしたPDFを反映する

OCRの実行はTomeで行います。SumiはPDFに含まれる文字情報の表示・選択・検索・注釈を担当します。

対象の書類で「… → OCRテキスト・Tomeとの連携」を開き、「Tomeの出力PDFを関連付ける…」から成果物を一度指定してください。Tomeが同じ保存先のPDFを更新すると、Sumiが変更を検出し、ページ構成と紙面を照合して反映します。注釈・フォルダ・閲覧位置を引き継ぎ、Sumiの再起動は不要です。

通常8秒ごとに確認し、2回安定した状態を確認してから読み込みます。入力中は反映を延期します。ページ順・余白・紙面等が変わった場合は自動で差し替えず、理由を表示します。Tomeが別名で出力した場合は関連付け直してください。原本・外部の成果物は変更せず、Sumi側に以前のPDFの版も保持します。
